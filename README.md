# Tela de Login – HTML e CSS

Este repositório contém uma tela de login desenvolvida com HTML e CSS como atividade prática durante o curso do **Instituto PROA**. O projeto tem como objetivo praticar os fundamentos do desenvolvimento web, a estruturação de formulários e a estilização de interfaces.

A página consiste apenas na parte visual de uma tela de login, sem funcionalidades de autenticação, validação de dados ou integração com banco de dados.

## Funcionalidades

- **Estrutura HTML:** Organização dos elementos da tela de login.
- **Estilização com CSS:** Aplicação de cores, fontes, espaçamentos e outros elementos visuais.
- **Formulário de Login:** Criação de campos para entrada de usuário e senha.
- **Interface Visual:** Organização dos elementos para criar uma apresentação simples e intuitiva.

## Objetivo do Projeto

O projeto foi desenvolvido com finalidade acadêmica e de aprendizado, visando praticar conceitos fundamentais de HTML e CSS na construção de interfaces web.

## Tecnologias Utilizadas

- **HTML5:** Estruturação dos elementos da página.
- **CSS3:** Estilização e apresentação visual da interface.

## Como Executar

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto.
3. Localize o arquivo `index.html`.
4. Abra o arquivo em um navegador para visualizar a tela de login.

## Aprendizados

Durante o desenvolvimento, foram praticados conceitos de estrutura HTML, formulários, campos de entrada, seletores CSS, cores, espaçamentos e organização visual de elementos.

## Observações

Esta é uma interface demonstrativa criada exclusivamente para fins de aprendizado. Os campos não possuem validação, autenticação ou qualquer funcionalidade de acesso a uma conta.
